# NovaCraft Nexus

Создай современный одностраничный сайт для ивент-агентства NovaCraft Event Agency (NCEA), которое занимается организацией мероприятий на собственном Minecraft-сервере в вымышленной вселенной ТРА, губерния Нова-Люминис.

СТИЛЬ И ВИЗУАЛ:
- Тёмная тема (глубокий чёрный, тёмно-серый, фиолетовый) с неоновыми акцентами (бирюзовый, розовый, золотой). Киберпанк/ретро-футуризм с элементами пиксель-арта.
- Рамки и разделители в стиле ASCII/псевдографики (как в старых терминалах) — двойные линии, угловые символы ╔ ╗ ╚ ╝ ╠ ═, но использовать их как стилизованные графические элементы, не просто текст.
- Шрифты: для заголовков моноширинный пиксельный шрифт (Press Start 2P или похожий), для текста — читаемый гротеск.
- Анимации: плавное появление блоков, мерцание неона, эффект печатающегося текста для девиза.
- Фон: абстрактная сетка, звёзды, пиксельные частицы, возможно, летающие блоки из Minecraft (стилизованные).

РАЗДЕЛЫ САЙТА (все на одной странице, плавная прокрутка):

1. ХЕДЕР / ГЛАВНЫЙ ЭКРАН:
   - Логотип: стилизованная надпись "NCEA" в пиксельной рамке.
   - Название: NovaCraft Event Agency.
   - Девиз: «Создаём события, которые делают игру интереснее.»
   - Кнопка «Связаться с нами» (ведёт к разделу контактов) и кнопка «Дискорд-сервер» (ссылка на приглашение).
   - Анимированный фон: пиксельный городской пейзаж с налётом майнкрафта.

2. О НАС:
   - Заголовок в рамке: ╔═ О НАС ═╗
   - Текст: «NCEA — ивент-агентство и оператор игрового сервера. Мы создаём комфортную среду, проводим регулярные турниры, конкурсы и тематические события, поддерживаем честную и конкурентную атмосферу. Наша цель — развитие игрового сообщества ТРА.»
   - Перечисление основных направлений в виде «карточек» с иконками (меч для PvP, кирка для строительства, книга для квестов и т.д.).

3. НАШИ МЕРОПРИЯТИЯ (блок "Что мы делаем"):
   - Заголовок: ╔═ ИВЕНТЫ ═╗
   - Горизонтальный скролл карточек с типами мероприятий:
     - PvP-турниры (меч)
     - Строительные конкурсы (блок земли)
     - Квестовые события (компас)
     - Командные соревнования (щит)
     - Сезонные ивенты (подарок)
     - Ролевые и сюжетные игры (маска)
   - Каждая карточка с анимированной иконкой и кратким описанием.
   - Кнопка «Расписание» (пока неактивна, но выглядит кликабельно).

4. ПАРТНЁРСТВО И СОТРУДНИЧЕСТВО:
   - Заголовок: ╔═ ДЛЯ ПАРТНЁРОВ ═╗
   - Призыв: «Мы открыты к предложениям от организаций ТРА, спонсоров и медиа. Свяжитесь с генеральным директором напрямую.»
   - Большая выделенная кнопка «Написать в Discord» (открывает диалог с пользователем @yozekkk или просто копирует Discord-тег в буфер).
   - Рядом перечислены возможности: спонсорство, коллаборации, медийное освещение, совместные проекты.

5. ОТДЕЛЫ И КОМАНДА (можно скромно):
   - Заголовок: ╔═ РУКОВОДСТВО ═╗
   - Три карточки (или строки) с должностями, без фото, но с никами в стиле:
     • Генеральный директор: @yozekkk
     • Руководитель отдела мероприятий: @yozekkk
     • Глава техподдержки: @yozekkk
   - Можно подписать «Свяжитесь через Discord».

6. ПОДВАЛ (футер):
   - Девиз мелким шрифтом.
   - Ссылка на Дискорд, почта (заглушка).
   - Копирайт: © 2026 NovaCraft Event Agency. Все права защищены.
   - Анимированная пиксельная гирлянда снизу.

ФУНКЦИОНАЛЬНОСТЬ:
- Плавный скролл по якорям.
- Неоновая подсветка активных разделов в навигации.
- Модальное окно с формой обратной связи (не обязательно отправляет, просто дизайн) или прямая кнопка для Discord.
- Адаптивность под мобильные устройства.
- Загрузка с анимацией раскрытия центрального логотипа.

ВАЖНО: используй цветовую палитру, где основной фон #0a0a0f, блоки #12121c с рамкой #00ffff (бирюзовый неон), текст #e0e0ff, акценты #ff00ff и #ffaa00. Шрифт для рамок и заголовков — моноширинный, с засечками в стиле пиксель.

При создании сайта интегрируй реальные ссылки на Discord-сервер (заглушка) и дай возможность скопировать Discord-тег @yozekkk по клику.
